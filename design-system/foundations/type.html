Type

IBM Plex Sans for the interface, IBM Plex Mono for anything a machine measured or wrote: readings, timestamps, axis labels, paths. Sizes are half-step values because the app is dense and a full 2 px jump would push a card off a 1366 px screen. Weight does the ranking, size only sets the scale.

Families

Sans: "IBM Plex Sans", Ubuntu, "Noto Sans", sans-serif

Mono: "IBM Plex Mono", "Ubuntu Mono", monospace

IBM Plex carries the interface and ships as fonts-ibm-plex, a Recommends of the package. Ubuntu is the guaranteed fallback where that package is missing, which is why it sits second in the stack and not "Noto Sans". Both are OFL or Ubuntu Font Licence.

Letter spacing

Only two rules. Anything at 22 px and above tightens to −0.3 to −0.4 px. Anything below 11 px that is set in caps opens up 0.6 to 1 px, otherwise small caps close into a block.

Tabular figures

Every live number carries font-feature-settings: "tnum" 1. Without it the values twitch on each refresh and columns stop lining up.
