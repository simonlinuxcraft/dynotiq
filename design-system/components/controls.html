Controls

Small set on purpose. A settings page that needs a control this list does not have is a settings page asking the wrong question. Every control is overridden down to background-image: none, because system themes paint their widgets with gradient images that otherwise punch straight through the theme.

Switch

The only toggle. Off is the disabled surface, on is the accent, and the slider is a fixed near-white that does not follow the accent.

Rules

A switch takes effect immediately. There is no Apply button anywhere in the app.

Every setting has a second line saying what it actually does. A label alone is a guess.

Nothing that touches the system is a switch. Those go through a button and a confirm.
