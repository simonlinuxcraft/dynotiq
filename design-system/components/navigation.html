Navigation

One fixed sidebar at 208 px, three groups, no nesting and no collapse. Twelve pages fit on the shortest supported screen, so there is never a second level to hide anything in. The active page is the only accent-filled thing in the whole window.

Sidebar

Grouped by what the user came for: what is wrong, what the system is doing, what the numbers say. Group labels are 9.5 px caps and are not clickable.

Badge

A count, never a dot. It is always critical red, because a badge that can be any colour stops being a count and starts being a mood. Tabular figures so a jump from 9 to 10 does not shift the row.

Headerbar

46 px, a vertical gradient and one dark inset line at the bottom. It carries the current page and the state of the last scan, nothing else. The square dot takes the accent, the only place in the chrome that does.

Rules

The sidebar never collapses and never scrolls. If a page does not fit, the page count is wrong, not the sidebar.

Exactly one nav item is active. The accent fill is reserved for it and for the primary button.

Badges count things a user can act on. Never badge a page that only displays.
